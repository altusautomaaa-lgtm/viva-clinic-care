# VivaMed Brilliance

Crie um site institucional profissional, moderno e responsivo para a clínica VIVAMED | Clínica Popular, localizada em Nova Iguaçu – RJ.

IMPORTANTE:
O site NÃO pode ter aparência de template de IA, landing page genérica ou SaaS. Quero um resultado com aparência de site desenvolvido por uma agência profissional de branding/web design para uma clínica real.

A identidade visual deve ser baseada na marca existente da VivaMed:
- Verde escuro como cor principal
- Verde médio como cor secundária
- Branco como base
- Vermelho apenas em pequenos detalhes e elementos de destaque, inspirado no símbolo de coração/eletrocardiograma da marca
- Visual limpo, sofisticado e confiável
- Evitar excesso de gradientes
- Evitar glassmorphism
- Evitar cards excessivamente arredondados
- Evitar sombras exageradas
- Evitar elementos flutuantes desnecessários
- Evitar aparência futurista/tech
- Evitar ilustrações genéricas de IA
- Usar fotos reais de pessoas, médicos, atendimento e estrutura sempre que houver imagens disponíveis
- Priorizar composição editorial e fotografia profissional
